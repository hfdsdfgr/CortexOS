# 常见问题

先记录应用版本和完整错误提示；提交问题时使用可公开的合成例子，去除聊天、文件内容、路径和凭据等私人信息。

| 现象 | 检查与处理 |
| --- | --- |
| Ollama 连接失败 | 确认服务已启动并监听 `127.0.0.1:11434`；可在 PowerShell 运行 `Invoke-RestMethod http://127.0.0.1:11434/api/tags`，再回设置检测连接。不要为排错改为监听所有网卡 |
| 找不到 `ollama` 命令 | 安装官方 Windows 版后重新打开终端；先确认安装成功，再检查命令路径 |
| 已连接但无可用模型 | 执行 `ollama list`，必要时运行 `ollama pull qwen3:4b-instruct`；设置里选择完整下载的本地模型 |
| 模型被拒绝 | 应用不支持云端模型别名及远程服务；检查选中的模型来源与格式 |
| 回答截断或超时 | 查看本次终态，在设备承受范围内调整回答长度或超时；参数修改用于下一次回答。更长输出不保证更好结果 |
| 文件无法导入 | 检查 UTF-8 编码、TXT/Markdown 扩展名和 2 MiB 上限；网络路径、链接文件、二进制及常见凭据文件不在支持范围 |
| 导入后回答未用到文件 | 先将需要的行保存为知识并确认。当前只搜索已生效知识，不直接全文搜索文件 |
| 已确认知识未命中 | 核对工作区、自动查找开关、文件是否停用、查询词和容量。中文单字或同义表达可能不命中，可手动选择并预览 |
| 修改知识后仍用旧内容 | 保存草稿不会替换生效版本，需要审核确认；历史回答固定引用当时版本，不会被新内容改写 |
| 引用提示无效或找不到行 | 该提示只检查编号与文字范围；查看本次发给模型的内容，重新提问并核对回答，不要把格式正确当作事实正确 |
| 图谱空白 | 检查工作区、筛选与展开范围，使用适应当前视图；演示图与真实数据分开。WebGL 失败时使用列表与详情 |
| 聚焦感觉瞬间完成 | 在「图例与操作」检查「镜头过渡」。平滑模式为 420ms；跟随系统可能直接完成，立即切换始终直接完成。确认运行的是 v0.1.0 对应新版 |
| 无法启动第二个窗口 | 同一数据目录只允许一个应用进程，先检查已有窗口或任务栏 |
| 构建不能写入 exe | 正常关闭当前开发或 Release 进程后重试，不要在未保存编辑时强制结束 |

## 数据问题

数据目录以设置页显示为准。备份前正常退出应用，再复制整个目录；迁移前自动备份不能替代日常备份。当前缺少通用恢复与导出界面，不建议直接改库、删除迁移记录或用旧版本尝试打开新库。

## 提交可复现的问题

在 [Issues](https://github.com/marksimZ/CortexOS/issues) 提供：应用版本、Windows/WebView2 与 Ollama 版本、模型名、最短复现步骤、预期和实际结果，以及脱敏截图。性能问题补充节点/关系数量、是否同时生成和窗口尺寸。敏感安全问题按 [安全报告说明](../SECURITY.md) 处理。
