# 多中心关联探索交付

2026-10-21，对应已批准六步计划第3项，契约见ADR/0015-multi-center-exploration.md。

## 操作与保留规则

1. 选中节点，使用原“只看直接关联”进入单中心探索。
2. 选中范围内其他节点，点击“展开直接关联”，追加它的一跳关联；每个展开初始读取最多50个匹配节点，可继续读取50个。
3. 顶部紧凑列表按展开范围显示名称、真实计数、继续读取与收起；点击名称可定位该节点。列表最高160px并可滚动，复用V3按钮、间距和焦点，无新卡片体系。
4. 收起A只移除A这一展开来源。仍被B需要的共享节点、其位置和当前选中详情继续保留；显式“显示这个节点”产生的临时显示也保留。环不递归遍历，停用关系不带入范围。
5. 全部收起后停在空探索视图，不自动重开全图。详情仍可重新展开，或明确“返回全部节点”。存在临时显示时，空展开视图可以仍有临时节点。
6. 来源列表放在知识正文之后的“显示范围”折叠区；标题、状态、审核与正文仍优先。搜索/类型/审核/日期对全部展开共用；改变筛选或选择会清除临时显示，单独展开/收起不会。

跨页、工作区及演示状态分开保留在当前应用会话；重新启动不恢复展开列表，明确保存的坐标与相机沿用原数据库机制。探索动作不修改知识、关系或执行事件。

## 数据与增量修改

- 原query_graph_nodes新增可选rootNodeIds，兼容rootNodeId，互斥、最多20个、不重复、逐项校验工作区；空数组与省略分别代表空探索/普通工作区。SQL返回去重的真实匹配量。
- graph-query.ts按中心读取前缀并按实体ID合并，记录成员的所有展开来源；多中心额外用一行集合查询取得去重总数，各页与连线共享同一快照，迟到响应不能覆盖新范围。仅显示端点间当前有效关系。
- Graph.tsx改为展开列表与来源状态，保留原编辑器、审核、历史、位置草稿、保存并发与导航；原单中心行为仍可单独使用。GraphExplorations.tsx只负责范围列表控件，graph-design.css增加列表及按钮分组规则。
- 演示数据显式标记，走相同合并/收起流程，页面内生成匹配页；正式工作区仍只经Rust读取数据库。
- 修复清除筛选与关系分页的焦点竞争：读取进行时保留焦点请求，等DOM提交且控件启用后恢复；GraphRelations以组件内引用定位新关系条目。读取失败保留上次画布并明确提示，不用空数据冒充成功。

无表/迁移/索引/依赖或Tauri权限变化。Cargo.lock和package-lock.json未改动。

## 真实验证

原生WebView2用70节点隔离库：A一跳59、B一跳17，存在11个重叠节点，真实并集65；两个首批50/17合并为56个节点。继续A后65，收起A后17，最后一个收起后0；未把59+17误称为并集。包含A→B→共享节点→A的环、停用边及未展开的两跳节点。

专项还覆盖：工作区越界/重复/超过20与互斥参数拒绝、节点来源由两个变一个、隐藏选择详情保留、跨范围坐标草稿保存、回到原页面和工作区恢复、真实IPC旧结果延迟后收起范围、WebGL降级、临时显示在所有展开收起后仍保留、演示与真实工作区隔离。浏览前后知识与关系逐项相等，只有用户明确保存的视角变化。

原有分页/Unicode/101个历史修订及跨页关系编辑通过；知识编辑/审核、并发关系比较、视角重启及清除筛选键盘焦点的原生专项通过。浏览器演示独立验证多中心、全部收起/返回以及WebGL降级；不以浏览器结果代替原生结果。

## 边界与停止点

同时展开最多20个，额度之和最多10,000；保存仍限制最多1,000个改动坐标。前缀重读、计数/排序扫描及密集连线无边分页的限制保持，尚未单独测量20中心或更大图性能，不能据请求上限宣称流畅规模。前轮读取耗时数据属于当时版本，本轮没有发布新的模型/千节点性能结论。

相机保留用户当前视角，不因展开自动适应全图；实际截图可能有节点处于当前视口以外，可用“适应当前视图”。标签遮挡和关系阅读是下一切片；系统缩放、完整读屏、真实模型高负载/长时、安装升级仍待各自验收。未跑单元或全套测试。
