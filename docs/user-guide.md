# 使用指南

适用版本：v0.1.0。首次安装见 [开始使用](getting-started.md)。

## 工作区与对话

工作区隔离会话、知识、文件资料与图谱。切换工作区不会把正在生成的回答写入另一个会话；当前一次只执行一个生成任务。

输入框编写 Markdown 原文，眼睛图标预览排版，再返回编辑。问题和回答支持标题、列表、引用、代码及表格；回答可切换「原文 / 排版」，复制保留 Markdown。当前没有公式和代码语法着色，远程图片只显示说明。

生成中可以停止；取消、失败或超时保留已收到的回答并记录状态。重试产生新的执行记录。已发送消息会保存，未发送草稿和未保存编辑不要当成重启后可恢复的数据。

## 查看一次回答的依据

会话默认开启自动查找已确认知识，也可以关闭。手动选用优先；预览显示本次可能选用的知识、版本和容量，发送时重新校验并保存实际请求。

回答的处理记录包含真实事件、配置、知识版本和请求快照。3D 执行轨迹将这些已保存事实转成节点，可定位原消息与当时的知识版本。旧运行没有请求快照时会保留缺失状态。

`[资料1]` 或 `[资料1:2-3]` 对应该次请求中的知识文字，可点击查看；编号只在这一次回答内有效。位置检查可提示无效编号、越界行和缺少引用，但不判断回答内容是否正确。文件起源与后续编辑的知识内容应分别核对。

## 建立和维护知识

1. 从回答选中文字后保存为知识，或在知识页新建。
2. 填写标题、正文与修改原因，保存草稿。
3. 检查完整内容后确认，使该版本用于后续查找和回答。
4. 再次修改生成新草稿，旧生效版本继续使用，直到确认新版本。

「版本历史」从知识详情打开右侧抽屉，可查看旧内容、审核记录和版本差异。知识页与图谱详情复用编辑和审核操作。版本冲突需先核对变化，不能直接覆盖他人的新版本。

当前检索是中文双字词与拉丁词的词法匹配；单字、同义改写可能找不到。确认知识表示用户审核，并非系统核实事实。手动选择仍受版本、文件启用状态和容量限制。

## 使用资料文件

在知识页打开「资料文件」→「添加文件」，在系统选择器中明确选择单个 UTF-8 `.txt` / `.md`，最大 2 MiB。预览后确认导入，选择行范围保存为知识草稿，确认后才可用于回答。

应用保存文字副本，不修改、监视或自动同步原文件。行号以应用保存的文字为准。原文件更新后需重新选择导入，新增版本；旧引用仍指向旧副本。

停用文件后，从该文件建立的知识停止未来检索或选用；旧回答和执行记录继续保留。停用不是永久删除，历史对话文字也不会随之消失。

## 浏览知识图谱

「知识关系」使用当前工作区的数据库节点和关系；单独标记的演示图仅供体验，不写入工作区。

- 左键拖动旋转，右键拖动平移，滚轮缩放；节点列表也能选择对象。
- 选中节点查看知识、来源、关系与版本；添加、修改和停用关系会保留历史。
- 「展开直接关联」支持从多个中心查看邻域，按批次继续读取；收起展开只改变浏览范围。
- 搜索和筛选影响当前展示，不修改知识；暂时隐藏的选中对象仍可从详情核对。
- 「保存视图」保存视角和位置；移动节点不产生知识版本。恢复已保存视图会放弃当前未保存布局。

「图例与操作 → 镜头过渡」默认平滑 420ms，可改为跟随系统或立即切换。执行图在「图例与记录说明」提供同一设置；拖动和滚轮可打断动画。关联展开保留当前镜头，必要时使用「适应当前视图」。

WebGL 不可用时，仍可用列表与详情查看、编辑知识。图上空间接近不代表两个节点存在关系；关系含义以真实连线与详情为准。

## 离线与数据保留

本地模型服务停止时，已保存的消息、知识及处理记录仍可查看。关闭编辑器或正常关窗时会提示处理未保存内容；强制结束进程可能丢失未保存编辑。数据备份方式和升级边界见 [安装指南](getting-started.md)。
