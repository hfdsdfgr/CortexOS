# 知识页面：参考图布局适配

2026-10-20。视觉参考为reference/document-history.jpg。用户确认仅重排知识页，随后明确以现有聊天UI为底层、避免大改；后者覆盖最初的窄导航栏提案。

## 参考与取舍

参考图包含窄导航、上下分区的文档/历史侧栏、右侧正文。侧栏约占内容宽度四分之一到三分之一；尺寸为视觉估算，不是设计源文件参数。本项目保留聊天UI的品牌、文字导航、工作区、浅色Tokens、洋红强调色与顶部模型状态，不照搬紫色、Mac窗口按钮或图中的文件导入/恢复/差异高亮。

布局：原有聊天风格导航 | 知识列表（上）＋版本历史（下） | 正文、草案操作、对照与来源。外层只在知识页复用聊天AppShell；聊天页排布不变，图谱与设置保留现状。侧栏历史用真实版本的修改说明、版本号、保存/审核时间，节点可点击；知识尚未选择时显示明确空态。

## 尺寸与交互

沿用chat-design.css语义颜色、Segoe UI/微软雅黑、导航圆角。知识内部采用列表和时间线，无卡片叠加。条目侧栏250–350px，正文保留可读行宽；1100px以下收窄侧栏。800px以下沿用导航抽屉，选择知识后先展示正文，版本历史在下方；返回列表保留原入口。1366×768、1920×1080与375px使用实际截图检查。

原有搜索/状态筛选、新建、编辑、草稿离开保护、并发冲突、审核确认、生效版对照、历史选择、来源摘录/哈希、原会话和图谱定位保留。审核仍确认最新草案，查看历史不改变生效版本。版本历史默认展开，也保留查看版本下拉框。版本内容保持纯文本，不假装提供参考图的富文本或行级diff。

## 组件与边界

AppShell/Sidebar增加知识页复用，Sidebar按当前页面设置导航与工作区目标，聊天会话列表仅出现在聊天。KnowledgePage提供上下分区，KnowledgeInspector通过React portal将既有版本历史显示到侧栏，保持单次读取与原有编辑/审核生命周期；图谱检查器继续在原位置显示历史。新增knowledge-design.css只覆盖知识页排布；版本按钮基本样式供同一检查器复用。没有数据库迁移、权限变更或新增依赖。

验收：既有知识全流程、上下文/检索/执行图定位和聊天回归，加上侧栏版本点击与两尺寸截图；命令及结果以milestone-log为准。完成本UI切片后停止，不进入P1-B。
