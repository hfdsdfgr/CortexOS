## 布局

参考左侧白色浮动栏约占17%，外侧轻边框、大圆角；右侧为近白背景和连续留白。没有明显贯穿主区的顶部导航。欢迎标题与输入框左边对齐，内容宽度约占右侧78%，约从全图26%横坐标开始。输入框下方有较浅的本地/来源条。参考主区没有卡片网格。

实现采用两列：侧栏clamp(224px,17.2vw,330px)，外留8px；主区保留52px低强调TopBar以呈现真实模型状态。1366与1920目标窗口使用78%主区内容宽度。欢迎标题位于上半区，输入框随其下方；有消息后正文独立滚动，输入框固定于内容区底部。800px以下侧栏改模态抽屉，保留键盘导航。

## 组件与状态

- Sidebar：品牌、真实页面入口、工作区、会话列表、底部本地身份。将参考中的项目和Chats映射为工作区和会话，保留真实选中状态。
- Composer：白色大输入框、下方模型设置入口、圆形亮粉发送按钮；未满足发送条件呈中性禁用态，生成中显示停止按钮。中文输入法Enter组合输入保持原有保护。
- EmptyState：CortexOS欢迎标题及原创点阵符号。未建工作区提供创建；模型离线提供设置入口；浏览器明确为预览。
- Message：用户消息使用浅灰区域，助手正文直接排版，操作行可复制、保存知识、检查执行和进入3D；生成/失败/取消/输出上限均为真实状态。
- CognitiveInspector：默认关闭，复用真实事件与上下文快照；对话布局不常驻额外右栏。
- Hover只改变表面或文字；键盘焦点可见。错误保留并可恢复；不为视觉匹配隐藏数据或插入演示会话。

## 有意差异与验收

保留CortexOS品牌、Windows原生窗口装饰，不复制Zeraix标志、macOS红黄绿按钮或用户头像。参考的Daily/Developer、Skills、Automation、文件夹导入没有对应已实现功能，不制作可点击假入口；使用对话/知识/图谱/设置导航。顶部增加真实Ollama状态，下方来源条映射为已实现的知识上下文。正常发送条件满足时才用亮粉按钮。
