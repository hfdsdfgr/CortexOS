# 参考图界面落地

2026-10-20。范围为现有对话、知识、图谱、执行轨迹、设置、资料文件及编辑/确认状态。依据 reference/1.png 至 8.png，并以用户最新要求补回必要边界；不照搬图片中的演示文字、虚构操作或参数。

## 布局与层级

- 共享浅色背景、紫色选中和主操作，发送沿用粉色。导航 64px，会话列表 224px，知识列表 240px；导航仍可展开，知识列表仍可收起。
- 对话阅读和输入区最大 960px；知识正文外层最大 1040px，包含自适应左右内边距。正文 17px、行高 1.75，窄屏回到 16px。
- 页面标题 28–38px，知识标题 28–38px，普通控件 14–15px。主要动作使用实色，次要动作使用白底细边框，回答附近的操作使用文字按钮。
- 输入框、搜索、弹窗、顶栏和独立侧栏保留边框；正文、列表行和历史条目通过留白分组。连续圆角使用原生 [corner-shape: squircle](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/corner-shape)，支持检测失败时使用普通圆角，不增加库或裁剪表单内容。
- 常规按钮按内容定宽，高度至少 36px，内边距 7px 14px。知识确认、弹窗保存、设置保存、图谱操作都使用同一规则，避免按钮拉伸或过度留白。禁用按钮使用中性底色。

## 信息按需展开

- 设置分为模型连接、本地数据、关于三个分类；模型参数继续使用原有展开区。分类保持 DOM 和设置草稿，不改保存、校验或错误处理。
- 知识类型、查看版本、状态和生效版本用独立文字片段排列；版本抽屉、来源、对照和引用继续使用原逻辑。
- 图谱节点列表默认收起，显式按钮在所有尺寸可用；WebGL 降级仍强制保留节点列表。关系明细按需展开，位置编辑和历史保留。
- 执行说明、资料预算放入展开区。界面元信息减少间隔点连接，小灰字不承担错误、未保存、停用、版本变化等必要反馈。
- 不把生成图中的状态选择标签加入真实产品，不添加未实现的恢复版本、富文本、云服务或导出操作。
