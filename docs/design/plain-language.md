# 界面用词规范

2026-10-20，按用户要求：大白话优先，严谨、正确、完整为前提。覆盖聊天、知识、资料文件、图谱、处理记录、设置与新错误提示。

| 原表达 | 用户看到的表达 | 保留的含义 |
| --- | --- | --- |
| 原生来源 | 资料文件、添加文件 | 用户主动选择的本机文件 |
| 来源快照 | 保存的文字副本 | 当时保存的内容，不随原文件变化 |
| 草案 / 生效版本 | 草稿 / 回答使用的版本 | 保存草稿与检查确认是两步；确认不等于事实已核实 |
| 上下文 | 本次会用的资料、发给模型的内容 | 包括说明、选用知识、对话和问题，记录实际版本 |
| 候选 / 纳入 / 预算 | 找到的知识 / 选用 / 容量上限 | 找到不等于选用，选用不等于已执行或已证实 |
| 运行审计数据 | 本次回答的处理记录、详细记录（原始数据） | 真实事件、时间和原始字段仍可查看 |
| 内容哈希 | 内容校验码（SHA-256） | 校验算法和原值保留，不表示内容可信 |
| 温度 / 最大输出 | 回答变化程度（温度）/ 回答长度上限（Token） | 采样参数与Token单位不变；Token不等于字数 |
| 适应图谱 / 聚焦节点 | 显示全部节点 / 移到选中节点 | 相机操作与节点选择逻辑不变 |

模型服务限制、文件编码/大小及保存范围等必要限定放在相关说明或展开区中，不增加主界面小灰字。保留模型名、Token、UTF-8、SHA-256等会影响操作或核对的名称，并用普通话解释；单位、范围、权限和确认步骤保持明确。

准确性检查：资料预览只说“选用”，实际处理记录才说“使用”；手动检查不冒充系统核实。停用文件停止新的检索和选用，历史对话可能仍含旧内容。当前仅查找已确认知识，不直接全文搜索文件。记录模型名称不等于保存了模型文件版本，即使模型相同，重新提问也可能得到不同回答。

设置页移除“尚未授权任何来源”“文件导入开放前不会读取资料”两处过时说明，改为当前真实的主动选文件政策。历史用户内容、事件字段和已有保存记录保持原样。
