# HTML 参考界面规范

2026-10-22。用户明确要求用 `reference/CortexOS 3D_ Full Prototype(1).html` 完全替换此前视觉设计。此规范取代 V3 的视觉方向；原业务边界、数据真实性和可打断图谱操作继续有效。

## 参考与落地

直接读取 HTML 的 CSS 与布局，并用 Edge 打开四页截图对照；参考的外部 Google Fonts 请求在检查中阻止，不引入线上字体依赖。参考配色：背景 #EEF1F7、蓝雾 #DAE2FB、绿雾 #D4EEE8、主文字 #1B2230、强调 #4F5BD5、知识青绿 #4FB6A8。采用本地字体回退，中文使用系统 UI 字体。

外层16px留白与16px区域间距；侧栏252px，聊天正文最大720px，依据栏336px；知识页列表290px，设置页200px标题列与最大640px表单。浅色半透明玻璃、20px面板圆角、12px条目圆角和胶囊按钮均来自参考。暗色使用参考的深蓝绿背景；字体普通/中/粗权重从400/500/600调整至380/450/500，避免系统中文字体在550时匹配到过粗字重。深色强调色为可读性调整至#7F8BFF，非逐像素不加判断地照抄。

现有功能比参考多，使用相同控件和折叠详情容纳，不删除审核、对比、来源、检索、运行、跨页定位、视图保存、错误或草稿保护。演示冲突、向量检索、重排器、虚构统计及Git式提交不接入正式界面。依据栏只显示既有get_run返回的当次知识和估算量，SVG连线只表示纳入本次请求。

## 五项细节

1. 主层级靠参考背景与1%–3%的细微表面叠色，玻璃使用细高光而非粗边框；输入框内高光与外环分开，聚焦增加双层阴影。
2. 外观支持浅色、深色、跟随系统，偏好保存在本机；暗色降低文字权重，图谱配色随主题同步。
3. 仅新到达的回答片段以小范围blur/opacity依次呈现，已显示正文不反复播放，输入编辑与引用原始偏移不变；按钮图标用统一盒子和居中排列。
4. UI数字使用tabular-nums，容量和计数保留稳定空间；网格用minmax与断点适应窗口，标题balance、正文pretty并保留中文断行。
5. 窗口拖动复用系统能力，反馈采用短时弹性运动，成功提示2500ms自动消失；错误、待处理和未保存状态保留。减少动态效果时取消模糊/弹性，图谱镜头继续遵循独立用户选项。

## 2026-10-22 交互补充：菜单、滚动和面板操作

保留上述视觉方向和页面排布。本次只统一共享交互，实际命令、问题修正和截图见里程碑同日“界面易用性优化”。

- 应用内单选菜单统一复用`SelectMenu`。保留真正的select、原label、value、disabled和change事件，用浏览器Popover顶层呈现选项，避免被玻璃面板或模态窗口裁切。选中勾选、键盘方向/Home/End/Enter、Esc、点击外部关闭和焦点状态保持一致；不支持Popover的环境保留系统选择器。文件选择和日期等系统能力继续沿用原控件。
- 菜单背景、文字、选中态、12px圆角与阴影使用现有Tokens。选项至少34px高，长名称换行；位置根据视口边界调整，可向上展开。弹出列表的可访问名称使用“字段名＋选项”，避免与原字段重名。
- 滚动沿用浏览器能力：10px轨道、2px透明内边形成约6px可见滑块、透明背景、无上下箭头；悬停/拖动只改变颜色。浅深主题各自设滑块Tokens，强制颜色模式保留系统可见性。阅读区域保留稳定滚动占位，内部滚动不把外层页面一起带走。
- 长面板采用共享`panel-header / panel-body / panel-footer`结构；标题及关闭按钮不参与正文滚动，有保存/确认操作时固定底部。覆盖处理记录、引用、历史、资料文件、知识与关系编辑、图谱/执行详情和窄窗导航。保留错误、保存禁用及未保存修改确认。
- 版本历史为非模态抽屉，通过React Portal挂到body，避免页面玻璃表面和顶栏形成的层叠遮挡；原有版本选择、跨页定位与关闭焦点处理不变。
- 回答依据在面板标题行右侧收起，窗口按钮独立留在上方；关闭后在聊天区右侧提供展开入口。桌面展开偏好本机记忆，窄窗临时展开独立管理，跨断点不覆盖桌面偏好。窄窗使用原生模态dialog，支持Esc及关闭后返回展开入口。

验证区分浏览器、原生WebView2和系统设置：1366×768、1600×900、1920×1080检查浅深主题；375/800为内容视口检查，600px高度用于长表单/文件预览压力检查，不等于修改Windows缩放。2026-10-23用户确认已在真实150%系统缩放下验证所有功能，反馈无问题；真实读屏仍待人工补充。下文的“本轮”验证结果保留当时记录，后续验收以windows-delivery和milestone-log为准。
