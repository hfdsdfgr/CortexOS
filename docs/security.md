# 安全与隐私

更新于 2026-10-22，适用于 v0.1.0。漏洞报告见 [SECURITY.md](../SECURITY.md)。本文描述已实现边界和剩余限制，不代表独立安全审计或合规认证。

## 数据保存在哪里

工作区、会话、知识版本、来源文字副本、实际模型请求及执行事件保存在本机 SQLite。设置页显示实际数据目录。请求快照可能包含私人问题、历史消息和选用知识；迁移备份同样含有用户数据。

数据库未加密，也没有独立于 Windows 账号的访问控制。应用信任当前账号、本机服务和运行环境，工作区隔离用于防止应用层串用数据，不隔离拥有本机权限的其他进程。通用恢复、导出和永久删除界面尚未提供。

## 联网范围

模型调用由 Rust `reqwest` 固定发到 `http://127.0.0.1:11434`，禁用代理与重定向。请求前检查本地模型来源和格式，拒绝云端别名。模型自身是否遵循输入仍取决于模型与本机服务。

应用没有遥测、外部字体、CDN 或静默资料上传。安装器缺少 WebView2 时可联网获取运行时，Ollama 的安装和权重下载也需独立联网；Ollama 自身的网络行为与更新由其配置决定。用户主动打开外链可能由浏览器发起网络访问。

## 文件访问

Rust 原生选择器只读取用户明确选择的本机普通 UTF-8 `.txt` / `.md` 文件，单文件最大 2 MiB。前端不接收任意路径读取权限；导入使用工作区绑定、限时且一次性的预览票据。

读取拒绝网络路径、符号链接/目录重解析点、非 UTF-8、二进制/NUL 和常见凭据名称；Windows 句柄核对实际路径。应用不扫描目录、不改写或监视原文件。

保存后使用本地文字副本和不可变来源版本。停用文件阻止未来检索与手动选用，但不会删除历史副本、请求或对话，也不会清除旧对话里已经包含的文字。

## 不可信内容与 Markdown

文件、知识和模型输出均按数据处理，不获得系统提示、工具调用或任意程序执行权限。模型建议不会自动触发文件或系统操作。

Markdown 由 `react-markdown` / `remark-gfm` 呈现，未启用原始 HTML 执行。链接只接受显式 HTTP、HTTPS 和 mailto，带 `noopener/noreferrer`；远程图片只显示文字说明，代码块只展示。引用位置检查仅验证能否定位当次资料，不验证事实或证据支持关系。

## 后端与数据完整性

- Tauri 显式列明业务命令和主窗口能力，不开放任意 shell、SQL 或 URL 代理。
- 工作区与实体归属在后端检查，SQL 参数化；相关数据采用复合外键或事务检查。
- 知识版本、审批、来源与执行事件保持历史，生效版本切换有事务和并发修订校验。
- 模型输入快照与运行准备原子保存，准备失败不发送模型请求。失败或取消保留已收到输出并记录终态。
- 迁移先核对校验和并创建一致性备份，保留原始迁移内容。
- 生产 CSP 限制脚本、字体和页面来源；Release 排除 debug 专用 CDP、数据目录与服务替身入口。

开发服务器仅 loopback；开发 CSP 为 Vite 刷新作必要放宽，开发模式用于可信本地代码。测试使用隔离数据和合成问题，不能用其结果替代正式工作区的恢复验收。

## 公开仓库与预发布限制

仓库及 v0.1.0 预发布资产现已公开。二进制未签名，自动更新未启用，安装包不包含 Ollama 或模型。项目许可证尚未指定，依赖分发审查、完整数据管理和独立安全审计仍待完成。

[Windows 交付记录](windows-delivery.md) 区分正式 Release、隔离调试伴随包与人工待验收项；有构建和专项验证不代表所有环境的安全与兼容性保证。请按 [安装指南](getting-started.md) 备份重要数据，并在反馈中去除私人内容。
