# CortexOS v0.1.0 — Windows 预发布版

2026-10-22。本版本供内部试用，源码功能基线为 `b7ad417`，不代表全部开发计划已完成。

## 本版功能

- 本地 Ollama 对话、工作区与会话保存；输入支持 Markdown 编写和预览，回答支持 Markdown 显示。
- 知识编辑、审核、版本历史与对比；明确选择的 UTF-8 TXT/Markdown 文件导入、版本快照和来源定位。
- 基于已保存数据的知识图谱与真实执行轨迹；镜头默认平滑过渡 420ms，支持跟随系统或立即切换。
- V3 浅色界面、紧凑导航和按需打开的详情面板。

## 安装

下载 `CortexOS_0.1.0_x64-setup.exe`，适用于 Windows x64，安装到当前用户。安装包未签名，可能出现 Windows 发布者提示。

本包不包含 Ollama 和模型，请自行安装并配置本地服务。已有 WebView2 时可离线安装应用；缺少运行时时，安装器需要联网获取 WebView2。

升级或试用前请关闭 CortexOS，并自行备份重要数据。安装器默认卸载会保留应用数据。

## 验证与限制

已完成类型检查、前端与 Windows Release/NSIS 构建；本轮 3 项原生 WebView2 专项检查覆盖实际镜头插值、节点选择和执行图。三个内容视口 1366×768、1600×900、1920×1080 已检查。隔离安装升级和数据保留证据见 `docs/windows-delivery.md`，不等于本正式包在干净系统的完整验收。

正式 Release 已启动，用户交互验收仍待完成。本轮未运行单元测试或全量测试。150% 系统缩放、真实读屏、干净系统安装与长时间真实模型稳定性尚未验收；通用备份恢复、签名、自动更新、Decision Lab、固定评估集及 LoRA 未完成。运行记录只展示应用实际执行事件，不表示模型隐藏思维链。
