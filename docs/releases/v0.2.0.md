# CortexOS 0.2.0

本地优先的 AI 认知工作台，将项目对话、知识管理、回答依据和 3D 图谱放在同一个工作区。

本版围绕日常使用体验更新：

- 统一对话、知识、图谱和设置界面，支持浅色、深色与跟随系统。
- 对话旁可查看本次回答选用的知识及对应版本，按需打开完整处理记录。
- 长记录、版本历史和详情面板保留标题与关闭入口；编辑时保存操作保持可见。
- 统一菜单和滚动条，完善侧栏收起、键盘选择、Esc 关闭与焦点返回。
- 保留 Markdown 对话、知识编辑审核、版本比较、文件副本、来源定位和可打断的 3D 镜头操作。

## 下载与使用

下载 `CortexOS_0.2.0_x64-setup.exe`，安装前关闭正在运行的 CortexOS。用同页 `SHA256SUMS.txt` 核对安装包；重要资料请保留副本。

安装包不含 Ollama 或模型。文档中的 Qwen 只是轻量示例，也可使用其他通过本机 Ollama 部署、与应用兼容的本地 GGUF 对话模型。准备步骤见[开始使用](https://github.com/marksimZ/CortexOS/blob/v0.2.0/docs/getting-started.md)。

## 当前范围

这是 Windows x64 **预发布版**，安装包未签名。浏览器和原生 WebView2 专项已覆盖主要操作及三种窗口尺寸的浅深主题。2026-10-23，用户已在 Windows 150% 系统缩放下验证所有功能，反馈无问题；真实读屏和长期真实模型负载仍待人工验证。通用备份恢复、导出和永久删除界面暂未提供。

安装、升级与发布后人工验收的具体范围见[Windows 交付记录](https://github.com/marksimZ/CortexOS/blob/main/docs/windows-delivery.md)。
