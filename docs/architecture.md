# 架构与数据流

更新于 2026-10-22，适用于 v0.1.0。产品边界见 [PRD](PRD.md)，数据定义见 [数据库契约](database-schema.md) 和实际迁移。

## 模块边界

```text
Tauri / WebView2
  React UI：对话、知识、图谱、设置
  useStudio：工作区、会话、生成和共享状态
  Hash 导航：实体 ID、明确版本、返回定位
      │ 类型化 Tauri commands / run-scoped Channel
Rust 应用层
  commands：参数、工作区归属、生命周期
  db / knowledge / graph / graph_query / execution
  retrieval / sources / citations / ollama
      ├─ rusqlite → 本机 SQLite + FTS5
      ├─ 原生文件选择器 → 明确选中文件的受限读取
      └─ reqwest → 127.0.0.1:11434 / Ollama
```

前端负责呈现和交互，不直接读文件、数据库或模型服务。Rust 执行权限校验、事务、来源读取和网络请求。命令清单在 `apps/desktop/src-tauri/build.rs`，窗口能力在 `src-tauri/capabilities/`；新增能力应有具体业务需要。

## 一次回答

1. UI 提交工作区、会话、问题和选用知识 ID/预期版本；预览与正式请求复用上下文组装逻辑。
2. Rust 校验归属和版本，按开关执行已生效知识词法检索，按容量组装知识与完整历史轮次。
3. 同一准备事务保存消息、ExecutionRun、上下文清单、精确请求快照、引用与实际准备事件。准备失败时不调用模型。
4. Ollama 服务接收已经准备的请求。模型检查、发送尝试、实际收到响应及终态按真实时刻记录；流通过携带运行标识的 Channel 送回 UI。
5. 输出周期性保存，结束时保存回答、引用位置检查和终态；取消、超时与中断保留已收到内容。重启为遗留运行追加中断事实。
6. 执行图从保存的事件、快照与消息投影，点击可查看当次内容并定位原实体。没有快照的历史运行不补造内容。

实际存储使用 `execution_runs`、追加式 `execution_events`、`context_snapshots` 等结构；ExecutionStep 的可视化来自实际事件投影，不另造一张名称相同的事实表。

## 知识、文件和版本

`knowledge.rs` 以事务创建不可变知识版本与审批记录，分别维护最新草稿和生效指针；确认后同步 FTS5 派生索引。`retrieval.rs` 按工作区查找当前可用的生效版本，手动选择和自动候选共用预算和来源状态校验。

`sources.rs` 经原生选择器创建工作区绑定的短期预览票据，确认后保存文件文字版本与事件。知识证据绑定具体文件版本、行范围和摘录。重新导入增加版本，停用阻止未来选用，历史副本与请求保持可读。源文件全文不直接进入检索索引。

`citations.rs` 将回答中的资料编号绑定当次请求，保存位置与错误；`AnswerContent` 和 `MarkdownContent` 呈现引用及文本，不赋予内容执行权限。

## 两种图与共享导航

| 视图 | 数据来源 | 主要代码 |
| --- | --- | --- |
| 知识关系 | 工作区知识、当前关系与历史修订 | `Graph.tsx`、`graph-query.ts`、`graph_query.rs` |
| 执行轨迹 | 实际运行、事件、请求和输出 | `ExecutionTrace.tsx`、`execution-data.ts`、`execution.rs` |

两者共用 `GraphViewport.tsx`、节点/连线渲染、标签与相机，但视角保存与领域数据独立。知识图按需分页读取，支持多中心范围；节点与关系保留稳定实体 ID。演示数据明确标记并保持独立，不写入工作区。

`navigation.ts` 在 URL hash 保存工作区、会话、运行、节点、知识版本及返回定位，不写正文。知识详情和编辑器在知识页、图谱中复用。根部 `useStudio` 和 React 状态承担现有状态管理，尚未引入 Zustand 或路由库。

图谱使用按需帧循环、批量节点与连线及有限标签。动画第一帧开始计时，默认 420ms，操作可打断；偏好可选跟随系统或立即完成。接口额度与性能承诺分开，测量见 [文档索引](README.md)。

## 数据与进程

SQLite 位于 Tauri 应用数据目录，设置页显示路径。启用外键、WAL 和版本迁移校验，升级前生成一致性备份。应用限制同一数据目录由单进程使用，数据库阻塞访问放入后端阻塞任务。未发送草稿和浏览范围等部分状态只在当前会话内保留；业务版本与实际运行保存到数据库。

Release 不包含 debug 专用的隔离目录、测试服务和 CDP 环境入口。正常开发使用 Vite 的 loopback 服务，生产使用打包资源和严格 CSP。安全细节见 [安全与隐私](security.md)。

## 决策与未来范围

单桌面应用与直接服务调用是当前结构；具体取舍保存在 [ADR](ADR/)。Decision Lab、固定评估集、向量检索、工具工作流及 LoRA 仍属后续设计，当前架构图不把它们画成已运行服务。
