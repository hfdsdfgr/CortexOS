# 产品要求与当前范围

2026-10-15，Phase 1。

## 面向谁

需要围绕本地项目持续讨论、保留上下文并审核 AI 产出依据的个人用户。首个目标环境为 Windows 与 8 GB 显存笔记本。

## 关键任务

1. 创建工作区、连接本地模型并对话。
2. 保存并重新打开会话，查看实际使用的上下文与执行状态。
3. 将回答片段变成待确认知识，审核后使用，修改时保留版本。
4. 通过列表与图谱理解知识关系，定位证据及冲突。
5. 后续固定问题和配置，对比知识修订前后的回答。

## 当前可交付行为

四个主入口为对话、知识、图谱、设置。主导航保留文字、当前位置和键盘访问；支持直接进入页面、刷新和返回。设置位于导航底部。

对话页支持工作区创建、会话列表与重命名、流式回答、停止、复制、错误重试和实际执行详情。设置页检测本地服务、列出已安装模型、校验和保存参数，并显示数据位置。首次创建工作区只要求名称；模型未准备好时提供明确的准备步骤，已有对话可离线阅读。

知识页展示空列表和审核说明；图谱页区分知识关系与执行过程，暂不生成节点。当前没有知识编辑、文件导入或 3D；执行过程从回答下方的二维时间线查看。模型设置可跳过；应用不主动安装服务或下载模型。

## 主要页面与完成条件

| 页面 | 布局 | 当前行为 |
| --- | --- | --- |
| 对话 | 会话栏、正文、底部输入区 | 可发送、停止、重试，运行状态和内容自动保存 |
| 知识 | 列表标题、表头、内容空态 | 不填充虚假知识，能返回对话 |
| 图谱 | 类型切换、空画布、语义说明 | 两类说明不同，无假执行事件 |
| 设置 | 分组表单、参数展开、本地数据说明 | 真实检测、模型选择、保存配置及准备步骤 |

宽度不足时收起空会话栏，设置表单改为单列；正文不发生页面级横向溢出。先验证 1440×900、1280×800、1024×768 与 800×600，额外检查 375px 浏览器宽度作为布局压力测试。

## Alpha 0.1 目标

真实本地回答、重启保留会话、知识草案与确认、版本历史、知识关系及实际执行图均可用。以用户任务完成验收，不以页面数量或装饰效果验收。性能数字以实测报告为准。
