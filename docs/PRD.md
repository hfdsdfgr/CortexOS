# 产品范围

2026-10-23，v0.2.0 当前范围。原始远期目标见 [development.md](../development.md)，实现状态见 [路线](roadmap.md)。

## 产品与用户

CortexOS 是本地优先的 AI 认知工作台，面向围绕项目持续提问、维护知识并核对回答依据的个人用户。当前交付目标为 Windows x64；已有原生验收基于 Windows 11。

核心任务是让用户完成：**提问 → 检查实际使用的内容 → 保存知识草稿 → 审核确认 → 再次使用 → 追溯修改。** 3D 视图辅助理解关系和执行记录，文本阅读、确认及版本对比在列表和详情中完成。

## 当前页面与行为

| 页面 | 用户任务 | 当前能力 |
| --- | --- | --- |
| 对话 | 与本地模型讨论项目 | 工作区和会话、Markdown、流式生成、停止重试、手动选用知识和自动查找、回答引用 |
| 知识 | 整理可复用内容 | 搜索筛选、草稿与确认、生效版本、版本历史抽屉、对比、文件文字副本和来源定位 |
| 图谱 | 探索关系和回答过程 | 知识图与执行图分离，真实实体选择、邻域与多中心、来源查看、跨页定位、关系修订和视角保存 |
| 设置 | 准备本地服务及调整回答 | 连接检测、本地模型选择、参数保存和数据目录查看 |

应用固定连接本机 Ollama；模型未准备好时仍能浏览已有数据。文件导入仅支持明确选中的 UTF-8 TXT/Markdown、单文件 2 MiB，先从文件摘录并确认知识，再参与回答；当前不直接检索文件全文。

## 业务不变量

- 工作区与实体归属在后端检查，跨页定位使用稳定 ID 和明确版本。
- 保存草稿与确认生效是两步；新草稿不覆盖旧生效内容。
- 一次回答保留实际配置、请求、使用的知识版本与事件，历史记录不随新知识改变。
- 知识审核是用户判断；引用检查是位置校验，两者都不冒充自动事实验证。
- 执行图只展示真实事件和已保存内容，不读取或宣称重建隐藏思维链。
- 界面使用最新 HTML 参考对应的共享控件和 Tokens；主流程聚焦任务，详情按需展开。

## 验收与后续

当前发布为预发布版，不等于所有原始阶段已完成。窗口内容视口与隔离原生流程已有专项记录；2026-10-23，用户已在 Windows 150% 系统缩放下验证所有功能，反馈无问题。真实读屏、干净环境安装、长时模型等剩余人工流程仍待验收。数据管理完善后，再进入 Decision Lab、固定评估与可选 LoRA，具体门槛见 [路线](roadmap.md)。
