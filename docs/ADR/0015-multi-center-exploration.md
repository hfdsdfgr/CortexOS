# ADR 0015 — 多中心关联探索

2026-10-21。对应已确认计划第3项，复用ADR0014读取/历史/视图契约及永久V3。不修改表、迁移、模型、知识或执行事件。

探索状态为工作区内的有序展开列表，每项包含中心ID与读取上限。普通工作区视图与“全部展开已收起”的空探索视图分别表示；返回全部节点是明确动作。原“只看直接关联”继续以当前节点开启单中心探索；“展开直接关联”追加中心，“收起此处展开”仅移除该中心。

每个展开范围按当前有效的一跳关系读取，初始50，包含符合筛选的中心自身；全部中心共用筛选。节点ID去重，同时记录其所属的全部展开来源。收起A后只留下仍属于其他展开的节点及显式临时显示节点，保留位置和当前详情。环不递归展开；停用关系不扩展范围。展示连线仍来自已加载端点间的当前有效关系。

query_graph_nodes增加可选rootNodeIds，与原单中心rootNodeId互斥，最多20个且逐项校验归属，拒绝重复ID；空数组表示空探索，省略表示普通工作区。该集合查询提供真实去重总数，避免把各中心计数相加。各中心继续复用原SQL分页，各批次与连线共享同一快照；迟到响应不能覆盖新展开列表。

前端按中心分别保留读取额度及成员来源；单次展开初始50、可继续读取50，合计读取额度最多10,000，最终显示最多10,000个节点（包含临时显示）。这是交互上限，不是性能承诺。继续使用前缀重读策略；不新增缓存框架、依赖或Tauri权限。

展开范围以紧凑可滚动列表呈现，名称、真实计数、继续读取和收起按钮均可通过键盘操作。收起后焦点移到相邻范围，最后一个收起后移到“返回全部节点”；详情保留，可再次展开。显示来源放在详情的折叠区。搜索/展开变化时复用已有加载反馈，出错保留草稿并允许重读/收起。工作区、演示及跨页返回各自保留当前会话内的范围状态，不新增永久探索记录。

验收：重叠邻域、环、停用关系、各中心分页与去重计数、来源保留、全部收起/重新展开、筛选与迟到响应、工作区/演示隔离、位置保存、WebGL降级和键盘焦点。仅运行必要原生集成场景、类型检查/桌面构建和实际三尺寸截图；不跑单元或全套测试。完成后停在第3项门槛，标签避让及桌面交付仍后续实施。
