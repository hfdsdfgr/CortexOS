# ADR 0012 — P1-C2a 批量绘制与关系读取

2026-10-21。用户要求按计划继续，沿用当前UI。本切片交付绘制批次优化、等值读取和真实模型共存检查，完成后停止；多中心展开/收起、数据库邻域分页、系统缩放、完整读屏和打包仍单独验收。

使用现有Three.js InstancedMesh按节点类型分组，业务ID保持原UUID。箭头合为一个批次，保留每条关系的颜色、位置和方向。实例索引仅映射当前批次节点数组；每次筛选、数量或位置变化更新矩阵和包围球，防止旧位置被剔除或点错节点。选中轮廓仍为独立非交互对象，标签仍最多7项。保持按需绘制和列表降级。

用户在本切片期间更新永久V3规范：以最新共享Tokens、低饱和材质、细线/箭头和GraphCamera为准，保留节点形状及实体语义。实例对象标记graphNode供相机判断空白拖动；点击选择调用同一个可中断聚焦流程，关闭/Esc返回探索视角。列表已处理的Esc标记preventDefault，避免再次触发相机退出。性能观测留在独立测试模式。窗口外壳及权限变化属于用户已完成的V3工作，本优化不扩展权限。

关系历史由逐关系查询改为一次工作区限定LEFT JOIN，按原edge ID及版本降序分组；保留完整历史、停用记录、字段类型、空关系行及返回结构。不改变数据库、权限或模型服务接口。颜色从继承Tokens读取并预先缓存，避免逐箭头重复读取DOM样式。

同一隔离数据库分别由旧/新二进制运行基线，以完整GraphData的SHA-256验证输入一致。V3更新前的前后对照和更新后的最终观测分开报告；不把相机动画、布局/材质变化造成的差异全归为批量绘制收益。V3适应全图动画420ms，最终基线等待500ms再开始350ms空闲采样。

额外检查所有节点形状及同类型多实例的实际鼠标选中、筛选后索引变化、移动后包围球、单击聚焦和返回视角、原有编辑/历史/视角/执行图。真实Ollama检查只用合成问题和隔离数据；如服务未运行，用已有安装临时启动回环服务，并仅清理本检查拥有的进程。GPU数据注明设备整体值，不将脚本绘制率等同屏幕FPS或主线程时间等同整个应用CPU占用。结果与限制见graph-performance-p1-c2a.md和milestone-log.md。
