# ADR 0011 — 图谱交互先于批量绘制优化

日期：2026-10-20；状态：P1-C1 实施。

以用户当前 workspace-design.css / reference-ui-implementation.md 为视觉基线，不重做导航、画布布局或知识编辑。复用 GraphData、稳定实体 ID、现有命令与视角保存。直接关联只读取当前有效关系，两端均可成为邻居，排除停用关系并按节点顺序去重。范围包含中心节点，初始最多50个，继续展开每次增加50个；只展开一跳，点另一个节点后可明确重新指定中心。

搜索、类型、状态、时间筛选继续作用于范围。选中节点被隐藏时保留详情，显式“显示这个节点”只临时显示该节点，筛选改变后取消临时显示。列表和关系列表也按50项逐步显示。全图数据仍由已有 load_knowledge_graph 一次读取；这是显示分页，不是数据库分页，未声称解决数据读取规模。关系仍展示完整修订理由、方向、时间和停用状态，添加起点/终点选择，不把用户登记关系误称为系统核实的证据。

复用执行视图的会话内 Map 模式，按工作区/演示分别保留搜索、筛选和关联中心/展开量；不写数据库。节点列表选择后将焦点移到详情，Escape收起列表后回到按钮。WebGL失败仍使用同一范围的列表、详情和操作。画布样式从自身继承的语义 Tokens 读取，使用户最新主题覆盖生效。

清除筛选后焦点移到首个节点；列表分页后移到新增第一项，关系分页后移到新增第一条摘要。关联范围展开完成后移到“返回全部节点”，返回后移到列表按钮。统一在React更新后恢复焦点，避免按钮移除后焦点落到页面根部。

本轮验证交互，并记录100/500/1000节点、1000/5000关系的原生合成绘制基线。只记录实际能测到的准备/读取时间、交互绘制次数及空闲帧；不把自动拖动绘制率称为精确屏幕FPS。完整CPU/GPU/显存、实际模型同时生成、实例化/分组绘制和安装包留在P1-C2，依据测量再优化。本轮不改变模型调用、数据库、权限或依赖。
