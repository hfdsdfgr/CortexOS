# ADR 0016 — 图谱标签与关系阅读

2026-10-22。对应已确认计划第4项，保持V3、节点形状/材质、相机、数据读取、编辑审核和执行图事实。

标签按选中节点→直接邻接节点→未选中时的可见节点排序；当前镜头重新投影并检查屏幕边界、标签间距与实际可见面板遮挡。最多24个复用DOM槽，最多7个节点标签；优先级低且放不下的标签隐藏，全文继续在可搜索列表/详情中查看，不宣称解决了3D几何遮挡。

优先选择靠近节点的上/右/左/下位置，短引线保留锚定关系，不将文字任意推远。选中节点在镜头外或完全被面板覆盖时不强制浮出边界。长标题省略时保留独立的状态标记。尺寸在文字/状态变化后批量测量，避免每标签每帧交错读写布局；空闲保持按需绘制。无Worker或新依赖。

选中时突出实际相接的有效连线，其他连线弱化；几何方向与关系类型保持不变。知识图在原折叠图例中新增“显示选中节点的连线名称”，默认关闭，最多3个且排在节点标签之后参与避让。详情继续用原“相关关系”读取完整端点/类型/历史，画布名称不冒充已验证证据。

标签层不接管鼠标或键盘，不改变实体点击映射。知识图和执行图复用节点标签避让，执行图不新增知识关系开关。所有修改仅影响呈现，不保存知识或执行事实。

验收：密集/长中英文标题、选中项位于节点数组末尾、边界/面板/重叠裁剪、缩放与窗口变化、连线名称开关、旧点击/筛选/位置/相机/多中心及执行图兼容、空闲不持续绘制；实际原生1366×768/1600×900/1920×1080截图。只做必要类型/桌面构建与集成检查，不跑单元或全套测试。完成后停止；系统150%/完整读屏/安装升级属于第5项。

候选在实际绘制时投影/排序，计算量随已加载节点及相关连线增长；24槽只是DOM上限，不是恒定CPU成本或10,000节点性能承诺。窗口/面板观察器仅在实际变化后重测，不通过反复订阅自身触发持续绘制。
