# ADR 0008：生效知识词法检索

日期：2026-10-19。范围：P1-A，用户选择默认开启、按会话关闭、中文夹杂英文术语与代码。

## 索引与排名

复用bundled SQLite FTS5。中文及CJK连续字符预处理为重叠双字词，拉丁字母/数字按边界拆词并转小写，交给unicode61索引。按当前问题去重并排除有限常见问句词；最多64个查询词，用安全生成的引号词串OR连接，SQL参数化。输入只产生字母数字词，不执行用户MATCH语法。

固定测试中，默认unicode61和trigram均无法以“发布”匹配连续短句“项目发布计划”；双字词方案可以。8个固定中文/术语/代码查询的预期首项全部命中（见retrieval.rs测试）。此为最小样本验收，不是通用准确率；单个CJK字符不检索，拼写纠错、同义词和语义召回尚未实现。

FTS索引只含knowledge/context/decision的生效版本。审批事务同时更新索引；草案修改不更新索引。迁移0006在同一迁移事务内回填旧生效版本。查询额外JOIN主表校验工作区与effective_version，索引不充当知识事实源。

排序为bm25（标题权重5、正文1）升序，再按node_id稳定打破并列。BM25统计来自本机同一FTS表；候选内容严格按工作区过滤。不同工作区语料可能影响分值，不把分数解释为概率或置信度。参考：[SQLite FTS5官方说明](https://www.sqlite.org/fts5.html)。

## 预算与审计

候选查询取21项，用额外一项判断是否超过20项上限，再保存前20项；超出部分仅记录截取标记，不声称保存全库候选。手动选择优先固定版本并保留原预算报错。自动资料至多5项，限额为手动资料和当前问题占用后剩余预算的一半；按整个知识正文纳入，不静默截断。之后按原政策选最近完整对话。

每项记录node/version、标题、正文、BM25分数、UTF-8增量预算、是否自动纳入和原因。手动重复项标manual_selected，自动新增项标included，其他为auto_limit/auto_budget。manual_selected表示已由手动上下文纳入，不计自动纳入数量。快照和context_knowledge_items包含实际发送的全部知识；retrieval_results持久化候选审计、复合版本外键、工作区触发器和不可变保护。manifest升级为schemaVersion3，旧manifest无retrieval字段时保持原展示。

retrievalUsed表示运行执行了查询流程，不等于有命中或回答引用了资料。预览复用查询和预算，读取时不创建运行、事件或候选记录；实际发送重新解析生效版本，预览不是锁定承诺。手动版本变化仍要求用户重选。

## 实际事件与失败边界

延续P0-A原子准备：同步校验、解析知识、实际FTS查询和预算先完成，运行/消息/快照/候选/事件同一事务提交。开始和结束时间在查询真实发生处采集，并用于retrieval_started/completed事件；elapsedMicros只测查询处理，不是模型或整轮耗时。接收时间在准备入口采集，事件显示顺序不倒置。

关闭开关不生成检索事件。无词/无命中仍记录真实查询结果状态。准备或索引读写失败保留草稿、回滚且不调用模型，不创建不完整运行；沿用P0-A边界，未实现准备阶段失败运行列表。日后异步来源检索再引入持久化准备状态，不能用虚构失败步骤填充。

## 会话开关与界面

conversation_retrieval_settings缺省为true，涵盖已有会话；只有实际更改时存一行。开启/关闭按工作区和会话验证，使用一个新命令。首次在尚无会话的输入区切换开关时创建空会话并转移草稿与手动选择，后续按会话持久化；切换中禁用发送。新会话默认开启，重启保留旧会话选择。

输入区只有一个自动检索复选框；候选和原因放在上下文预览、执行检查器及真实检索图节点内按需展开。保持现有浅色布局，不增加常驻结果卡片。文件授权、导入和回答引用解析属于P1-B。
