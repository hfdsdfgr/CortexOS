# ADR 0006：原子上下文快照与显式知识选择

日期：2026-10-18。状态：已实施，P0-A。

用户批准将最小知识上下文闭环前移。保留原有工作区、消息、run/event、知识版本和 provider，增加一份不可变完整请求快照及有外键约束的知识引用。preview_context 与发送共用组装逻辑；模型阶段只使用已提交的 PreparedRun.request。

选择 knowledge/context/decision 的当前生效版本，客户端带预期版本；审批竞争返回可恢复错误。资料作为数据消息纳入，用户审核不等于事实验证。history 按原规则整轮保留；新增排除原因。UI 以折叠清单、原生复选框和按需展开正文实现，不增加依赖。

采用整笔运行/消息/快照事务而非提前提交空运行：同步组装和校验失败保留编辑框，存储失败整体回滚，均不触发模型。真实网络工作开始后才有模型检查/请求/响应边界及失败终态。该选择细化原方案的“创建运行→组装”事务边界；没有跨越网络的长事务。未来异步检索需要独立可取消准备阶段时再扩展状态机。

复用 get_run 返回 snapshot，减少额外接口；选择列表只在当前进程保留，历史运行输入始终持久化。旧 run snapshot 为 null，不补造 system 内容或权重身份。请求哈希是 serde_json 默认对象序列化 UTF-8 的 SHA-256；完整模型权重未固定，仍按模型标签调用，因此不保证精确重放或逐字一致。

当前知识候选通过既有 list/get 接口读取生效内容，小规模列表存在逐节点请求；待分页/邻域阶段按实测合并接口。知识正文在 manifest 和 request 中重复存储受预算限制，暂不增加内容寻址去重。执行图和自动检索仍属后续切片。
