# ADR 0017 — Windows 内部交付验证

2026-10-22，六步计划第5项。保持V3和现有数据/模型逻辑，仅补充内部打包与交付检查。

使用已有Tauri NSIS，明确当前用户安装，提供简体中文和英文。正式包仍为0.1.0，未签名，仅内部开发使用；不包含Ollama和模型，不启动自动更新或公开发布。已有WebView2可离线安装应用；缺少WebView2时默认引导程序需要联网。依赖/模型再分发许可未完成审查，不作为公开发行包。

安装升级检查使用独立产品名CortexOS Delivery Check、标识com.cortexos.deliverycheck及仓库artifacts目录，避免覆盖正式安装项和正式数据库。0.0.9与0.1.0均来自本次相同源代码，仅版本覆盖不同；这是实际安装器的版本升级冒烟，不是历史发行代码兼容证明。调试伴随包允许现有仅debug的隔离数据/CDP入口；正式release保持这些入口关闭，不为自动化新增生产后门。正式release与调试伴随包的验证证据分别记录。

检查安装文件哈希与版本、真实安装器退出码、安装前后同一隔离库中的消息/知识/关系/来源/运行和视角、重启及数据库完整性。另用6版合成数据库验证现有6→7迁移、一致性备份与原记录保留。不迁移或读取正式工作区。

复用现有生成取消、服务异常、正常关闭和中断恢复专项；必要时增加较长可控HTTP流观察，明确不代表真实Ollama稳定性。真实窗口移动/缩放与键盘/可访问树检查和实际读屏分开记录。系统缩放不擅自修改，CDP视口或模拟设备比例不冒称系统150%。无法自动覆盖的事项保留人工清单及未完成门槛。

验收要求：可定位的内部release包、隔离安装/版本升级及数据保留记录、实际窗口与关键键盘路径证据、异常恢复记录、已测规模/模型条件和未验证项。150%系统缩放、真实读屏和长时真实模型如未实测，阶段仅为部分验收，不进入Decision Lab，不宣称P1-C整体完成。
