# ADR 0009：明确选择文件、来源快照与版本证据

2026-10-20，P1-B1实施方案。下一切片P1-B2才解析回答引用。

用户动作：知识页→来源→选择TXT/Markdown→预览→确认导入→指定起止行→建立知识草案→审核→下次检索使用→来源中查看固定版本。原文件改变后手动重新选择，产生新来源版本；旧知识/运行继续指向旧快照。

权限边界：新增choose_source/commit_source/list_sources/get_source/revoke_source/save_source_knowledge及discard_source共七个主窗口命令。choose_source不接收前端路径，只由Rust原生文件选择器获得单文件；预览使用一次性、工作区绑定、10分钟有效的内存票据，取消预览时作废。commit_source只接受票据，不重新读取路径。Rust校验本地绝对路径、扩展名、常见敏感名称、重解析点、普通文件、2MiB读取上限和UTF-8。前端没有fs/dialog通用权限，原文件不写入、不监控、不扫描目录；不导入网络路径。

存储：0007增加source_documents/source_versions/source_events/knowledge_source_links。版本快照、证据链接和来源事件不可修改；来源标题/路径仅作为本地定位，正文快照以SHA-256标识。正文统一CRLF为LF并移除UTF-8 BOM，分别保存原始字节哈希与文本哈希。知识证据固定来源版本及1基起止行，重复文字通过行范围区分；知识修订继承最初来源，不能冒称重新验证。

启用政策：导入本身不进入模型上下文。通过片段建立并审核的知识复用现有FTS与预算；实际请求快照记录对应来源版本/行/哈希。停用来源阻止其关联知识的未来自动和手动纳入，不删除旧知识/消息/运行快照；显式重新选择并导入视为重新授权。历史会话已有内容不因停用而清除。导入不等于事实验证，也不产生虚构的模型执行事件。

实现依赖：仅Rust增加官方tauri-plugin-dialog；不安装系统软件，不增加npm依赖。参考官方Rust API：https://v2.tauri.app/plugin/dialog/ 。测试用文件选择替身只在debug且隔离测试数据目录内启用，生产构建无法指定任意路径。

验收：明确选择/预览/确认、UTF-8与大小拒绝、无后台读取、来源重导入/旧版本定位、跨工作区隔离、知识审核/检索/停用、重启持久化。数据库迁移与文件权限属于必须验证的边界，本轮使用针对性原生集成检查与代码逻辑审查，不额外运行单元测试。具体结果写milestone-log。
