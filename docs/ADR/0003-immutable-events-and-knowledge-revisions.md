# ADR 0003：事件日志、知识草案与生效版本

状态：设计决定采纳；分阶段实现，不在 Phase 0 创建表。

原总纲同时将执行步骤定义为不可变事件，又给步骤行配置可更新状态。采用独立 `execution_events`：开始、完成、失败、取消各追加一行，运行和步骤状态作为投影更新。执行图只消费真实日志。

知识内容每次修改新增不可变版本。节点分别保存最新草案与生效版本；修改已确认内容时，旧生效版本继续被上下文使用，直到用户确认新版本。审批和撤销保存独立事件，确认在事务内检查预期版本再切换指针。

关系修改与证据关联也有修订历史，布局变化不属于知识修改。证据定位关联具体知识版本与来源内容版本。manifest 保存版本引用与哈希；精确重放需要获授权的上下文快照，缺失时明确说明限制。

该决定落实已制定规范中的语义修正。Phase 1 实现执行事件，Phase 2 实现知识与审批，Phase 4 补充版本来源和精确重放。
