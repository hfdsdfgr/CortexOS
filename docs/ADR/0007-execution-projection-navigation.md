# ADR 0007：执行事实投影与共享实体定位

日期：2026-10-19。状态：P0-B 已实施。

## 决策

沿用 execution_runs、execution_events、context_snapshots 和消息作为事实源；ExecutionStep 以只读展示投影实现。事件节点使用 run 范围内的 event:seq；知识和消息节点携带原实体 ID、固定版本及快照正文。模型不可见的内部推理保持未知。

时序边表达持久化事件顺序；上下文边表达实际请求纳入；输出边表达保存结果。只有真实记录存在才生成相应节点。旧运行没有完整快照时展示已知事实，未来检索和工具阶段在真实实现后再加入事件。

复用已有三维画布、列表降级和知识检查器。执行位置由顺序确定；0005 仅新增执行视角表，显式保存相机与目标点并使用修订令牌。暂不引入 execution_positions，因为当前没有自由布局编辑任务。运行事实和知识视角都不受执行视角保存影响。

URL hash 保存工作区及实体定位，浏览器历史提供前后导航，back 参数限制为图页。跨页知识链接固定版本，消息链接固定消息；返回链接保留执行节点。当前进程的视角草稿按工作区/运行隔离；退出后只恢复已保存值。

## 影响与升级条件

新增 list_runs/load_execution_graph/save_execution_view，复用既有读取 DTO 和能力注册。无需新依赖或通用状态框架。当前不是任意工作流 DAG；出现实际并行工具和依赖时，再设计持久化依赖与稳定步骤身份。大图分页和性能根据测量在 P1-C 收口。

验证覆盖事实对应、精确版本与消息导航、实时终态、失败/取消/中断、隔离、视角并发及离线重启。实际结果见 milestone-log。
