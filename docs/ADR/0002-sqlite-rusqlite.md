# ADR 0002：本地数据库采用 rusqlite

状态：架构决定采纳，Phase 1 实施；Phase 0 不安装数据库依赖。

选择 rusqlite。当前只有单用户本地数据库，事务和版本写入需要直接审查，暂不需要异步连接池。同步数据库工作通过 Rust 阻塞任务执行，避免占用异步网络执行线程。

Phase 1 使用 bundled SQLite 并在运行检查中确认 FTS5 能力；各连接启用外键，数据目录允许时使用 WAL。使用参数化语句、工作区范围约束和短事务；生成模型响应时不持有数据库事务。

迁移采用仓库内编号 SQL 与 `schema_migrations(version, checksum, applied_at)`，启动时按版本事务执行，校验已执行脚本的哈希。当前规模不引入独立迁移框架。迁移失败中止写入并提供明确错误；已有数据迁移前建立一致性备份。

代价：迁移和阻塞任务边界由应用维护。真实并发和查询需求超出当前结构后再评估连接池，保留 SQLite 作为数据层，不先换存储引擎。
