# ADR 0001：从单桌面应用开始

状态：采纳，2026-10-15。

应用放在 `apps/desktop`，文档放在根目录 `docs`；当前不建立 workspace 管理器、共享包、训练服务或空 feature 目录。npm 已安装且可直接使用，因此选 npm，不为单应用增加包管理层。

React 只保留页面导航和局部界面状态。业务模块在对应阶段进入实际代码；具有至少两个真实使用方后才提取共享包。既有目录可以平滑容纳后续模块，不需要先组织完整 monorepo。

代价：未来第二个应用出现时需增加 workspace 配置。当前维护一个锁文件和直接启动命令更容易验证。

Rust 使用项目级 `rust-toolchain.toml`，选择已获用户授权安装的 MSVC 工具链；不更改全局 GNU 默认。
