# CortexOS 3D

**让本地 AI 成为你的项目助手，也让每一次讨论沉淀为可追溯的知识。**

CortexOS 是一款本地优先的 AI 认知工作台，将模型对话、知识管理和 3D 关系探索放在同一个工作区。围绕一个项目持续提问，整理资料与结论，查看回答依据，再把经过检查的知识用于下一次讨论。

[下载 Windows 版](https://github.com/hfdsdfgr/CortexOS/releases/tag/v0.1.0) · [开始使用](docs/getting-started.md) · [使用指南](docs/user-guide.md) · [文档目录](docs/README.md)

## 用它做什么

### 和本地 AI 一起推进项目

为不同项目建立独立工作区，保存讨论、延续上下文，并选用自己的知识辅助回答。支持 Markdown 编写、预览与阅读，适合整理方案、学习笔记和技术讨论。

### 把零散资料变成可复用的知识

从对话或文件摘录中整理知识，先存为草稿，检查后再确认使用。修改保留版本，可回看旧内容、比较差异，并找到最初的资料与摘录位置。

### 看清知识之间的联系

在 3D 图谱中浏览知识和关系，从一个主题展开相关内容，或同时探索多个主题。结合搜索、筛选与详情阅读，把分散的信息连接成可以继续维护的知识网络。

### 知道一次回答用了什么

查看本次使用的知识版本、对话内容、模型配置和实际处理过程。通过引用回到对应文字，通过执行视图追溯原记录，方便自行核对与修正。

执行视图展示应用实际记录的处理过程；知识确认和引用定位帮助你核对内容，不替代事实判断，也不表示读取模型隐藏的思维链。

## 可以用在哪些领域

| 场景 | 使用方式 |
| --- | --- |
| 学习与研究 | 整理概念、阅读摘录和研究问题，连接不同主题，回查结论的资料来源 |
| 软件开发 | 沉淀架构约定、技术选型和排错经验，围绕已有项目知识持续讨论 |
| 产品与项目管理 | 保存需求、约束、方案和决定，梳理依赖关系，追踪内容如何变化 |
| 写作与内容创作 | 管理素材、人物设定、世界观和写作规则，让后续讨论参考已确认的内容 |
| 个人知识管理 | 将零散笔记整理成主题知识，维护关系、来源与版本，逐步建立个人知识库 |
| 工作资料整理 | 按项目组织文本摘录和经验记录，借助本地模型起草说明、梳理问题并核对依据 |

这些是现有对话、知识和图谱功能的使用方式。资料文件目前支持 UTF-8 TXT 和 Markdown；导入后需把所需文字整理并确认为知识，才会用于知识查找，暂不直接搜索文件全文。

## 选择适合自己的本地模型

**CortexOS 不限定使用 Qwen。** 你可以选择其他通过本机 Ollama 部署、且与当前应用兼容的本地对话模型，并在设置中切换。

文档中的 `qwen3:4b-instruct` 只是一个轻量模型示例，方便快速开始，不是必须使用的模型。可以根据设备内存、显存、语言和任务需求，选择适合自己的模型规模与量化版本；回答质量和速度取决于所选模型与硬件。

当前通过 `http://127.0.0.1:11434` 连接本机 Ollama，支持其提供的本地 GGUF 对话模型；其他部署工具的独立接口、远程服务和云端模型暂不在接入范围内。具体兼容条件见 [模型准备说明](docs/getting-started.md#2-准备本地模型)。

## 开始使用

1. 从 [Releases](https://github.com/hfdsdfgr/CortexOS/releases) 下载 Windows x64 安装包并安装。
2. 安装并启动 [Ollama](https://ollama.com/download/windows)，下载你选择的本地模型。例如：

   ```powershell
   ollama pull qwen3:4b-instruct
   ```

3. 打开 CortexOS，创建工作区，在「设置」检测连接并选择模型。
4. 开始对话，将有用内容保存为知识草稿，检查确认后用于之后的讨论。

完整安装、校验与备份步骤见 [安装与首次使用](docs/getting-started.md)，常见问题见 [排错指南](docs/troubleshooting.md)。

## 数据留在本机

会话、知识、文件文字副本和处理记录保存在本机，应用没有遥测，也不会自动上传工作区资料。已保存内容可离线阅读；生成回答需要运行本地模型服务。

文件由你明确选择，应用不扫描目录，也不修改原文件。原文件更新后可手动重新导入，旧引用仍指向当时保存的版本。数据库尚未加密，使用重要资料前请做好本地备份。详细边界见 [安全与隐私](docs/security.md)。
